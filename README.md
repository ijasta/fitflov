🏋️‍♂️ Gym Fitness Tracker

This is a gym website I built to make fitness tracking simple and more personalized. Instead of following random workout plans, users can enter their details like age, height, weight, and goals, and the website will generate workouts tailored specifically for them.

The best part is that it doesn’t stay static — the workout plan updates daily based on user progress, so it feels more like a real fitness guide rather than just a basic website.
